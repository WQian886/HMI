A1 · 安装包(Inno Setup) 详解

为什么选 Inno Setup

对比项Inno SetupNSISWiX
License免费商用免费商用免费但复杂
脚本难度Pascal 风格,简单有点诡异XML,学习曲线高
中文支持原生要插件要手动配
VS 集成命令行 ISCC.exe类似VS 扩展
适用场景中小型 Windows 应用极简安装企业级 MSI

结论:Inno Setup 是这个规模(单 exe,几十 MB)的最佳选择。

安装包要做什么

  1. 复制 hmi.exe 到 C:\Program Files\QianWei\HMI\
  2. 复制所有 Qt 依赖 DLL(windeployqt 自动收集,约 20 个)
  3. 复制 Qt 平台插件(platforms\qwindows.dll 等)
  4. 创建开始菜单快捷方式 + 可选桌面图标
  5. (可选)注册 HKCU 开机自启,带 --minimize 参数
  6. (强制)复制 LGPL LICENSE.txt(Snap7/libplctag 法律要求)
  7. 注册卸载项(控制面板 → 程序和功能能找到)

当前状态:installer/hmi.iss 已就绪(2026-09-08)

  • 文件:E:\qianwie\hmi\hmi\installer\hmi.iss(~2 KB)
  • 已配置:AppName, AppVersion, 安装路径, 语言, 自启动任务
  • 待补:Release 打包前,[Files] 段要从占位的 x64\Release\hmi.exe 改成打包 windeployqt 生成的 install_root\

打包步骤(从源码到 installer.exe)

1. 编译 Release 版本
   VS 切换到 Release 配置,或命令行:
   msbuild hmi.vcxproj /t:Build /p:Configuration=Release /p:Platform=x64

2. 用 windeployqt 收集 Qt 依赖
   D:\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe --release ^
       E:\qianwie\hmi\hmi\x64\Release\hmi.exe

   产出:x64\Release\ 下会多 ~20 个 DLL + platforms\ 插件目录

3. (可选)复制 LGPL LICENSE.txt 到 x64\Release\
   copy installer\LGPL_NOTICE.txt x64\Release\

4. 编译安装包
   "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" ^
       E:\qianwie\hmi\hmi\installer\hmi.iss

5. 产出
   installer\Output\hmi-setup-0.1.0.exe(约 50-80 MB)

分发注意事项

  • 代码签名:未签名的 exe 在 Win10/11 上会被 SmartScreen 警告,客户可能拒装。
    解法:Phase I 阶段买 EV 代码签名证书(~$200-500/年,3 年期)。
  • 版本号:hmi.iss 里 AppVersion 每次手动改。
    Phase I 时接 git tag 自动生成 + CI 自动构建。
  • 更新机制:Inno Setup 支持 /SILENT,/CLOSEAPPLICATIONS 等参数。
    可以做"在线更新"——Phase I 补,现在不做。
  • 升级检测:现在没做旧版本检测,直接覆盖装。Phase I 加版本检查。

实际打包要等阶段 I:installer 是最终给客户的东西,现在没必要打。先把功能做完,最后阶段 I 一起打包。

子任务

  • C1 · 驱动抽象 IDriver:connect/disconnect/read/write/stateChanged/tagsChanged;现有 ModbusMaster 适配成 ModbusTcpDriver;新增 S7Driver / EtherNetIpDriver

  • C5 · PLC→HMI 心跳:已有 inactivityTimeoutMs 改 linkWatchdog;加连接质量统计(RTT/丢包/错帧)
  • C6 · 通信诊断面板:隐藏画面 Ctrl+Shift+D;显示每个 driver 状态/RTT/错误/最近 10 条收发
  • C7 · LGPL 集成:第三方库 .dll 放 third_party/;installer 包含 LICENSE.txt;工程文件 commercial_license 开关

验收标准

  • ☐ 同时连 1 台 S7 + 1 台 EtherNet/IP + 1 台 Modbus TCP,UI 正常显示
  • ☐ 拔一根网线,挂的 driver 自动重连,不影响其他
  • ☐ PLC 侧能看到 HMI 心跳 Tag 1s 跳变
  • ☐ 心跳失联 5s → UI 显示"PLC-X 通讯故障"
  • ☐ 诊断面板显示每个 driver 的 RTT/错误率

AI 辅助重点:S7 和 EtherNet/IP 的 IDriver 包装层是 boilerplate,AI 写 1 小时出 200 行,你只调异常处理和时序。

第三方库 LGPL 集成策略

C1 客户用 LGPL **完全合法**,只要遵守 2 条规则。

库与 license 一览

协议库License商用
Modbus TCP自写自有✅ 无限制
S7Snap7(http://snap7.sourceforge.net)LGPL v3✅ 自用免费,商用按 LGPL 规则
EtherNet/IPlibplctag(github.com/libplctag/libplctag)LGPL✅ 同上
OPC UAopen62541MPL 2.0✅ 完全无限制

LGPL 规则(2 条)

  1. 动态链接:Snap7 / libplctag 编成 .dll,不编进主 exe
  2. 随包附 LICENSE:installer 里包含 LGPL 库的 LICENSE.txt

IDriver 包装关键原则

  • 所有 LGPL 库调用都在 S7Driver / EtherNetIpDriver 内部
  • 外部只看到 IDriver 接口(自有代码)
  • 这样你的核心代码 不被 LGPL 传染,核心闭源合法
